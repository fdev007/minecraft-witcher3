# Skins for the Steve body / Скины для тела Стива

The repository ships **no skins**: the community Geralt skins have no license that allows redistribution. Without a
skin, `mcw.ps1 install` uses Steve from your own Minecraft jar.

To play as Geralt, download a 64x64 Java skin with classic (4 px, "Steve") arms and either save it here as
`geralt.png` or pass it to the installer:

```powershell
.\mcw.ps1 install -Skin C:\path\to\skin.png
```

Skins that were tried (all classic arms, download them from their pages):

| Skin | Author | Notes |
|---|---|---|
| [Geralt of Rivia (The Witcher 3: Wild Hunt)](https://www.planetminecraft.com/skin/geralt-of-rivia-the-witcher-3-wild-hunt-6638260/) | Jaegerist | white hair with a long tail, scar, dark leather armour; uses the second layer a lot |
| [Geralt of Rivia (Witcher 3)](https://www.planetminecraft.com/skin/geralt-of-rivia-witcher-3geralt-z-rivii-wiedmin-3/) | darkrakso | very dark armour, little second layer |
| [Geralt / The Witcher 3 : Wild Hunt](https://www.planetminecraft.com/skin/geralt-the-witcher-3-wild-hunt/) | Oliver_Fitzovich | brown leather, chain mail, medallion |

PNG files in this folder are ignored by git.

---

В репозитории **нет скинов**: у скинов Геральта от сообщества нет лицензии на распространение. Без скина
`mcw.ps1 install` берёт Стива из твоего jar Minecraft. Чтобы играть Геральтом, скачай скин Java 64x64 с обычными
руками (4 px, «Steve») со страницы выше и положи сюда как `geralt.png` или передай `-Skin <png>`. PNG в этой папке
git не видит.
