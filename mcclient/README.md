# mcclient — скрытый клиент Майнкрафта (мод mcwc)

Настоящий клиент Minecraft 1.21.11 с Fabric-модом `mcwc`. Он играет Геральтом на сервере MCW (`..\mc`), но мир не
рисует. Кадр — ключевой цвет magenta, поверх него ванильные рука, предмет в руке и HUD. Оверлей
`..\overlay\mcw_overlay.exe` снимает это окно и кладёт поверх Ведьмака. Ввод и позу присылает мост (`..\bridge`). Схема
повторяет [SkyCraft](https://github.com/chasmlol/SkyCraft) без нативного кода (см. [../STEVE.md](../docs/STEVE.md)).

## Запуск

```powershell
..\mc\run_server.ps1          # сначала сервер: клиент сразу заходит на 127.0.0.1:25565
.\run_client.ps1              # gradlew runClient скрыто, ждёт мод, печатает {"pid","wall_s"} (~15 с)
.\run_client.ps1 -Stop        # погасить JVM игры
.\run_client.ps1 -Sound       # со звуком; -Decorated — окно с рамкой (отладка)
```

Мост (`..\bridge\bridge.py`) сам подключается к клиенту на 127.0.0.1:25601 и запускает оверлей. Порядок запуска не
важен.

Клиент запускается из dev-окружения Loom (`gradlew runClient`) со своей папкой `run\`, ник `Geralt`, без входа в
аккаунт. Сервер в offline-режиме слушает только 127.0.0.1. Папку `.minecraft` лаунчера клиент не трогает. Первый
запуск Loom докачивает клиентский jar и ассеты в `%USERPROFILE%\.gradle`, это несколько сотен МБ. Лог Minecraft —
`run\logs\latest.log`, вывод Gradle — `run\logs\gradle.out.log`.

## Как устроено

| Что | Как |
|---|---|
| Окно без фокуса | `WindowMixin`: окно создаётся скрытым и без рамки (`GLFW_VISIBLE/FOCUSED/FOCUS_ON_SHOW/DECORATED = false`), показывает его `Win.showBehind` через JNA: `WS_EX_NOACTIVATE \| WS_EX_TOOLWINDOW`, `SetWindowPos(HWND_BOTTOM, SWP_NOACTIVATE \| SWP_SHOWWINDOW)`. Показ средствами GLFW активировал бы окно, если процесс запущен с `STARTF_USESHOWWINDOW`, а Ведьмак без фокуса встаёт на паузу. Место и размер (клиентская область Ведьмака, 1:1) задаёт оверлей |
| «Всегда в фокусе» | `MinecraftMixin`: `isWindowActive()` = true. `MouseHandlerMixin`: `grabMouse`/`releaseMouse` только ставят флаг, без GLFW (системный курсор у Ведьмака); флаг нужен, иначе `handleKeybinds` не держит удар |
| Заголовок | `MinecraftMixin.createTitle` → `MCW Client`; по нему окно находит оверлей |
| Мир не рисуется | `GameRendererMixin`: в `GameRenderer.renderLevel` пропущен `LevelRenderer.renderLevel`. Остаются луч прицела (`pick`), рука, эффекты экрана. `MinecraftMixin`: кадр в мире очищается цветом `0xFFFF00FF` |
| Вход без ожидания | `LevelRendererMixin`: `isSectionCompiledAndVisible` = true. Иначе экран «Loading terrain» ждёт скомпилированную секцию под игроком, а их нет, и вход шёл по таймауту в 30 с |
| Рука | `GameRendererMixin`: свет руки — `LightTexture.FULL_BRIGHT`. Сутки MC с Ведьмаком не связаны, и рука выходила чёрной средь бела дня |
| Прицел | `GuiMixin`: пайплайн `GUI_TEXTURED` вместо `CROSSHAIR`. Ванильный прицел инвертирует цвет под собой, на magenta выходил зелёным |
| Настройки | `OptionsMixin` на каждом `return` из `Options.load` (на первом запуске файла нет, и `load` выходит сразу): без паузы вне фокуса, `inactivityFpsLimit = MINIMIZED`, без виньетки, музыки, обучения, онбординга, предупреждения о сторонних серверах; дальность 4; звук выключен целиком (`-Dmcwc.sound=true` — включить) |
| Ввод | `Control`: через ванильные обработчики GLFW (`KeyboardHandler.keyPress`, `MouseHandler.onButton/onScroll`, аксессоры `@Invoker`) с настоящим окном. Работает всё, как с клавиатуры: хотбар, удар, экраны |
| Поза (идёт за Ведьмаком) | `Control.startTick`: до тика игрока ставит его в точку моста. `PlayerMixin` отменяет `Player.travel`: ни гравитации, ни инерции. `aiStep` не трогаем, в нём взмах руки. Ход уходит серверу обычным пакетом; сервер его принимает (`noPhysics` Геральта, гейм-рул `player_movement_check=false`) |
| Ходит сам (режим Стива) | `follow{on:false}`: физика MC, WASD и прочее — от моста. Каждый кадр (`GameRendererMixin` → `Control.frame`, не чаще 60/с) — `eye` мосту: глаз на этот кадр, скорость по сдвигу за тик, высота глаза. Страховка: под ногами пустота на 16 блоков — без гравитации (рельеф ещё не пришёл); ноги внутри столбика земли — на поверхность |
| Дома, стены, полы | `Solid`: колонны `solid` от моста. Без статики — столбик до земли, со статикой — коробки 25×25 см на каждый твёрдый промежуток подколонны. Колонны, о которых `solid` ещё не пришёл, — по `Terrain`. Тем же списком — лошадь, которой правит игрок. Столкновения частиц идут с контекстом без сущности — их не трогаем. Страховка: ноги в земле — наверх всегда, в висящем промежутке (пол этажа, ступень) — только с глубины до 0,6, чтобы у стены не выбросило на крышу |
| Земля Ведьмака | `Terrain`: высоты колонн от моста (`terrain`). `EntityMixin` подмешивает столбики до этих высот в `Entity.collide` (к столкновениям с сущностями — их же берёт подъём на ступеньку), `BlockStateMixin` убирает игроку столкновения barrier (форма для прицела остаётся). Склон — мелкие ступени, проходятся сами |
| Рамка блока | `GameRendererMixin`: вместо мира — `extractBlockOutline` и свои линии (`Outline`): только видимые рёбра (в MC задние прячет глубина блока), у клетки рельефа (barrier) — только верх; грань, к которой встанет новый блок, подсвечена белым на 19 %. Не через `renderBlockOutline` — туда встроен Fabric, NPE без рендера мира |
| Трещины копания | `GameRendererMixin` (`mcwc$cracks`): блок из `MultiPlayerGameMode` (аксессор `destroyBlockPos`), стадия — `getDestroyStage`, ванильные `destroy_stage_N` на видимых гранях (`Outline.cracks`). Не умножением, как ваниль (`crumbling` испортил бы ключ magenta), а полупрозрачно (`entityTranslucent`): серую трещину оверлей снимает точно |
| Страховка от пустоты | `Control.guard`: ноги в земле — на поверхность, под ногами 16 блоков пустоты — без гравитации. Верхом — лошади, которой правит игрок (её физику считает клиент): 2026-10-04 лошадь на полном скаку ушла в пустоту там, где рельеф ещё не пришёл. Лошадь выталкивается наверх только при провале глубже 0,25 м, а сошедшая со ступени земли Ведьмака до 0,55 м и не прыгающая прижимается к опоре ванильным `move` (`snapDown`): в воздухе лошадь MC не разгоняется, на ступенях она тряслась и теряла скорость |
| FOV | `fov{v}` от моста — вертикальный FOV мира, как у камеры Ведьмака (`GameRendererMixin.getFov`), без эффектов бега. Рука — свои ванильные 70 |
| Курсор экранов | `ScreenMixin`: стрелка поверх экрана (свой слой, `nextStratum`) в точке курсора: у скрытого окна системного курсора нет. Двигает её `cursor` от моста через `MouseHandler.onMove`, как настоящая мышь |
| Без тоста | `ClientPacketListenerMixin`: при входе нет «Chat messages can't be verified» (сервер офлайновый) |

## Протокол с мостом

TCP 127.0.0.1:25601 (`-Dmcwc.port`), JSON-строки UTF-8, соединение одно: новое вытесняет старое. Входящие идут в
очередь задач Minecraft тем же путём, что события GLFW.

| Мост → клиент | |
|---|---|
| `key{k, a}` | клавиша GLFW (`GLFW_KEY_*`), `a`: 1 нажата, 0 отпущена, 2 повтор. Отпускание того, что не нажимали, игнорируется |
| `btn{b, a}` | кнопка мыши: 0 левая, 1 правая, 2 средняя, 3/4 боковые |
| `scroll{d}` | колесо: +1 вверх (предыдущий слот), −1 вниз |
| `char{c}` | символ (код Unicode), для чата |
| `cursor{dx, dy}` | сдвиг курсора открытого экрана (инвентарь, верстак, сундук) в пикселях окна; курсор зажат в окне. Экран открылся — курсор в центре (`Control.watchScreen`) |
| `release{}` | отпустить всё нажатое мостом |
| `pose{p, yaw, pitch}` | ноги в `p` (координаты MC) и взгляд; включает следование |
| `look{yaw, pitch}` | только взгляд |
| `follow{on}` | следовать за позой моста или ходить самому (режим Стива) |
| `fov{v}` | вертикальный FOV мира в градусах (0 — ванильный) |
| `outline{on}` | рамка блока под прицелом (по умолчанию да) |
| `terrain{c, reset?}` | земля Ведьмака: `[x, z, h_cm, ...]` — высота поверхности колонны в см; `reset` — забыть все |
| `solid{c, reset?}` | коллизия домов: `[[x, z, h, d, subs], ...]` — h земля (см) или null, d 1 — в колонне дверь, subs null (только земля) или 16 подколонн 25 см (`i + 4j`: x + i/4, z + j/4), в каждой `[низ, верх, ...]` в см, низ null — до земли |
| `world{hide}` | `false` — рисовать мир как обычно (отладка) |
| `npcs{l}` | прокси NPC Ведьмака: `[[сущность MC, x, y, z, vx, vy, vz, ширина, рост], ...]` — ноги и скорость (блоки/с). Перед каждым выбором цели (`GameRenderer.pick`) клиент ставит прокси туда, где NPC сейчас по скорости (не дальше 0,25 с), без интерполяции; размер — `LivingEntity.getDimensions` (`NpcProxies`). Старше 1 с — не трогает |
| `ping{ts}` | → `pong{ts}` |

| Клиент → мост | |
|---|---|
| `hello{v, mc, mod, name, title, key, world, win}` | при подключении |
| `state{tick, world, p, yaw, pitch, hp, food, sel, swing, block, screen, follow, terrain, fps, win}` | каждый тик клиента (20 Гц); `block` — поднят щит (мост: кукла Ведьмака в защите, `mcwf_guard`) |
| `eye{p, v, h, ground}` | пока ходит сам, каждый кадр (не чаще 60/с): глаз, скорость (блоков/с), высота глаза над ногами |
| `horses{h}` | каждый кадр (не чаще 60/с), пока рядом лошади (до 4 ближних в 48 блоках): `[id, x, y, z, курс тела, наклон, фаза шага, сила шага, flags, dx?, dy?, dz?]`, поза с интерполяцией кадра; flags 1 видна, 2 седло, 4 на ней игрок — тогда ещё ноги лошади от глаза игрока (`dx, dy, dz`): Ведьмак ставит её от глаза своей камеры, без дрожи на скаку. Пустой список — один раз, когда лошадей не стало |
| `arrows{a}` | каждый кадр (не чаще 60/с), пока рядом стрелы (`AbstractArrow`, до 8 ближних в 64 блоках): `[id, x, y, z, dx, dy, dz, vx, vy, vz, flags]` — позиция с интерполяцией кадра, направление по повороту стрелы, скорость в блоках/с; flags 1 воткнулась (`isInGround`, аксессор). Пустой список — один раз, когда стрел не стало |
| `pong`, `error{why, text}` | ответы |

## Сборка

```powershell
$env:JAVA_HOME = "$env:APPDATA\.minecraft\runtime\java-runtime-delta\windows\java-runtime-delta"   # JDK 21
.\gradlew.bat build           # проверка компиляции; run_client.ps1 собирает сам
.\gradlew.bat genSources      # исходники 1.21.11 (Mojang-имена) для чтения, ~3,5 мин
```

Пины — как у серверного мода (`gradle.properties`): Minecraft 1.21.11, Loader 0.19.5, Fabric API 0.141.6+1.21.11,
Loom 1.17.21 (последний под JVM 21). Цели миксинов сверены по декомпилированным исходникам 1.21.11. При
несовпадении клиент падает при запуске (`defaultRequire = 1`), а не молча.

## Чужое

Схема «скрытый клиент MC + кукла в другой игре» — идея [chasmlol/SkyCraft](https://github.com/chasmlol/SkyCraft) (Skyrim,
нативный плагин). Код здесь написан заново, у SkyCraft ничего не скопировано. Декомпилированный код Mojang в проект
не копировался.
