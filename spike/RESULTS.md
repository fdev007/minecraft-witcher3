## Что выяснили
1. **Порт 37001 слушает 0.0.0.0**, и после запроса брандмауэра у witcher3.exe правила Allow (TCP/UDP, Private+Public):
   exec доступен из локальной сети. Закрыть: правило Block из launch.md («Если 37001 слушает 0.0.0.0», нужен
   администратор) — Block в Windows сильнее Allow.
2. **Пределы exec 2047 / 1999 байт**, а не 32 767. Превышение — тишина, а не ошибка. Клиент, фейк, bench и мост
   переведены на эти пределы (`w3net.EXEC_MAX_CMD`, `EXEC_MAX_REPLY`, `bridge.toml` `batch.bytes = 1900`).
3. **`RoundF` отбрасывает дробь** (−1,6 → −1, 1,6 → 1; `mcw_roundtest`): 2286 из 40 001 целых см не переживали
   `(float)x / 100 * 100`, и `clear` в `mcw_batch` не находил блок (30 «потерянных» ящиков в batch_50). В моде
   теперь `MCW_Round = FloorF(v + 0.5)` — 0 ошибок; повтор batch_50/60 — 0 потерь.
4. **Пустая строка `""` в аргументе exec не разбирается** (`Failed to process command`); `"-"` в моде — синоним пути
   по умолчанию. Кавычки внутри строки — тоже ошибка разбора, `\` не экранируется.
5. **Запись в map через `thePlayer.поле[ключ] = …` в 5.00c не компилируется** («Left hand side is const»); чтение,
   Contains, Erase, PushBack через thePlayer — компилируются. Запись — методом класса через `@addMethod`.
   `@wrapMethod(CR4Player) function OnSpawned` (событие, обёрнутое словом function) компилируется и срабатывает при
   загрузке сейва (токен меняется, поля новые).
6. **`--reload` в запущенной игре** перекомпилирует все скрипты за ~10 с, новые exec-функции сразу доступны. Новую
   папку мода `--reload` не видит (список модов читается при старте), файл в уже установленной папке — видит.
7. **Пауза при потере фокуса — в движке.** Окно теряет фокус → движок открывает меню паузы и останавливает время.
   `theGame.IsActive()` — не фокус (остаётся 1). Закрытие меню скриптом не помогает: игра на секунду оживает и снова
   встаёт на паузу (наблюдение пользователя). Переменных конфига для этого нет. Exec при этом обрабатывается.
8. **Блок, поставленный там, где стоит Геральт, не выталкивает его вверх**: он стоит в блоке, пока не сдвинется.
   Мосту — не ставить блок в клетку игрока (как в MC) или телепортировать.
9. `theGame.ExitGame()` выходит в главное меню, а не из процесса.
10. Окно маркетингового согласия CD PROJEKT RED может всплыть в главном меню при запуске (не связано с
    `wasConsentPopupShown`); отклонено (Esc).
11. Камера в игре доворачивается сама; мышь (`rel`) крутит её примерно на 0,12° на пиксель, но точно навести на цель
    не получается — для тестов надёжнее ставить объекты по `cam` из `mcw_poll`.
