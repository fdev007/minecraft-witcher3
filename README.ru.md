# Minecraft × The Witcher 3

[English version](README.md)

Настоящий Майнкрафт *внутри* «Ведьмака 3: Дикая Охота». Ставь и ломай блоки Minecraft в Белом Саду, крафти по
рецептам Minecraft, дерись с NPC Ведьмака мечом, луком и щитом из Minecraft, езди на лошади Minecraft. На F4 Геральт
становится Стивом: рука, предмет и HUD Майнкрафта рисуются поверх картинки Ведьмака, ходьба — по физике Minecraft по
миру Ведьмака, а показывает всё Ведьмак своими средствами: свет, тени, коллизия.

Обе игры запущены одновременно. Безголовый сервер Minecraft отвечает за правила (блоки, инвентарь, крафт, мобы,
урон), скрытый клиент Minecraft играет Геральтом, а небольшой мост на Python переносит всё в Ведьмака через его же
отладочный канал скриптов. Нативного кода в Ведьмаке нет: только мод на WitcherScript и отладочный протокол движка.
Идея — от [SkyCraft](https://github.com/chasmlol/SkyCraft) (Minecraft в Skyrim).

> **Статус: экспериментальная альфа (0.1.0).** Сделано и проверено на одном ПК: Windows 11, Ведьмак 3 5.00c в Steam,
> Minecraft 1.21.11. Шероховатости будут; см. [Известные проблемы](#известные-проблемы).

## Что умеет

- Блоки Minecraft в мире Ведьмака: что можно поставить, сломать и скрафтить, решает Minecraft (верстак рядом,
  время копания — по правилам MC); показывает блоки Ведьмак своим светом и коллизией, Геральт стоит на них.
- **Режим Стива (F4):** от первого лица, рука, предмет и HUD Minecraft поверх Ведьмака, WASD, прыжок, присед и бег по
  физике Minecraft по рельефу, стенам и мебели Ведьмака (в дома можно зайти).
- **Бой:** меч и лук Minecraft по NPC Ведьмака (удар — удар Геральта его мечом, масштабированный уроном Minecraft;
  NPC парируют и уворачиваются по-ведьмачьи), удары NPC приходят игроку Minecraft (щит и броня Minecraft работают).
  Стрелы Minecraft летят стрелами Ведьмака и втыкаются в стены.
- **Лошадь Minecraft:** X — позвать, ПКМ — сесть; едет по физике Minecraft по миру Ведьмака.
- Вне вида от первого лица у Геральта тело Стива из коробок Minecraft на его костях (скин — любой свой), оно
  повторяет его анимации.
- Стартовый набор, меню крафта; взрывы Minecraft (крипер) — взрывами бочек Ведьмака.

## Установка

1. Скачай репозиторий (`git clone` или «Code → Download ZIP» и распакуй куда угодно).
2. Закрой Ведьмака и запусти в папке репозитория:

   ```bat
   mcw install
   ```

   (из PowerShell: `.\mcw.cmd install`). Скрипт проверит требования, затем:
   - один раз сделает бэкап настроек и сейвов из `Документы\The Witcher 3` в `%LOCALAPPDATA%\mcw\backups`;
   - спросит согласие с [EULA Minecraft](https://aka.ms/MinecraftEULA) для локального сервера;
   - скачает лаунчер сервера Fabric и соберёт два мода Minecraft (первая сборка качает Minecraft — несколько минут);
   - соберёт оверлей, если стоит Visual Studio;
   - поставит скриптовый мод в `<игра>\mods\modMCW`;
   - с REDkit: соберёт блоки и модели Стива и лошади из **твоего** jar Minecraft (~10 минут) и поставит их в
     `<игра>\mods\modMCWBlocks` и `modMCWModels`.

   Ключи: `-Lite` (без REDkit, даже если он есть), `-Skin <png>` (свой скин 64x64 с обычными руками для тела Стива;
   см. [assets_local/skins](assets_local/skins/README.md)), `-AcceptEula`, `-NoBackup`.
3. `mcw doctor` покажет, что найдено и чего не хватает.

Пути находятся сами (библиотеки Steam, GOG, лаунчер Minecraft). Переопределить — переменными окружения
`MCW_W3_DIR`, `MCW_REDKIT_DIR`, `MCW_MC_JAR`, `MCW_JAVA_HOME`, `MCW_PYTHON`. Сообщения скрипта — по-русски на
русской Windows, иначе по-английски; принудительно — `MCW_LANG=ru`.

## Игра

1. Двойной клик по **`mcw.cmd`** (то же, что `mcw start`). Запустится Ведьмак через Steam с отладочным каналом
   (`-net -debugscripts`; первый запуск после установки ещё и перекомпилирует скрипты), сервер Minecraft, скрытый
   клиент, мост и оверлей. Если Steam спросит про параметры запуска — разреши.
2. Загрузи сейв (всё проверялось в Белом Саду). **F4** — режим Стива.
3. **Окно Ведьмака держи в фокусе.** Без фокуса движок ставит игру на паузу, мир Minecraft замирает вместе с ней.
4. Остановить: `mcw stop` (мир Minecraft сохраняется). Ведьмака — сохраниться и выйти через меню или
   `mcw stop -CloseGame`.

`mcw status` — что запущено. Журнал моста — `bridge\logs\bridge.log`.

### Управление (окно Ведьмака в фокусе)

| Клавиша | Что делает |
|---|---|
| F4 | Режим Стива вкл/выкл |
| *Режим Стива:* W A S D, пробел, левый Shift, левый Ctrl | Ходьба, прыжок, присед, бег (физика Minecraft) |
| *Режим Стива:* ЛКМ / ПКМ / СКМ | Ударить или копать / поставить или использовать / выбрать блок. ПКМ с луком — натянуть, отпустить — выстрел; со щитом — блок |
| *Режим Стива:* 1–9, колесо мыши | Слот хотбара |
| *Режим Стива:* E | Взаимодействие Ведьмака, если есть подсказка (двери, NPC, сундуки, лут), иначе инвентарь Minecraft |
| *Режим Стива:* Q | Выбросить предмет из руки |
| *Режим Стива:* X | Лошадь Minecraft. ПКМ по ней — сесть, левый Shift — слезть (вне режима Стива X — Плотва) |
| F2 | Режим строительства без режима Стива: 9 / Mouse5 поставить, 8 / Mouse4 сломать, NumPad 1–9 слот |
| F3, PageUp/PageDown, 0 | Список крафта, листать, скрафтить (рядом нужен верстак) |
| F6 | Тест: крипер в 6 м |

Диалоги, катсцены и езда на Плотве сами возвращают управление Геральту, потом режим Стива возвращается. При первом
входе Геральт получает набор (железный меч, лук, инструменты, блоки, еда, щит, железная броня, стрелы); инвентарь
после смерти сохраняется. Звук скрытого клиента выключен.

## Лайт-режим

Без REDkit (или с `mcw install -Lite`) всё работает, но блоки Minecraft показываются ящиками Ведьмака, в катсценах
у Геральта своё тело, у лошади Minecraft нет модели. Поставь REDkit и снова `mcw install` — будет полная версия.

## Удаление

`mcw uninstall` останавливает всё и удаляет `modMCW`, `modMCWBlocks` и `modMCWModels` из папки игры. С `-Purge`
ещё и кэши сборки в `%LOCALAPPDATA%\mcw` (бэкапы остаются). Вернуть настройки Ведьмака из бэкапа — раздел «Откат»
в [spike/launch.md](spike/launch.md). Потом удали папку репозитория.

## Безопасность: отладочный порт

С `-net` Ведьмак слушает отладчик скриптов на **TCP-порту 37001 на всех сетевых интерфейсах** (проверено на 5.00c).
Пока игра так запущена, любой в твоей локальной сети может выполнять в ней скриптовые команды. В первый раз
брандмауэр Windows спросит про `witcher3.exe`: в публичных сетях не разрешай. Закрыть порт для других машин (мост
ходит через `127.0.0.1` и продолжит работать) — один раз в PowerShell от администратора:

```powershell
New-NetFirewallRule -DisplayName "MCW - block W3 debug port" -Direction Inbound -Protocol TCP -LocalPort 37000,37001 `
  -Program "<игра>\bin\x64_dx12\witcher3.exe" -Action Block
```

Сервер Minecraft слушает только `127.0.0.1` и работает в offline-режиме. Когда мод не нужен, запускай Ведьмака
обычным «Играть» в Steam, без `mcw`.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| `mcw doctor` показывает FAIL | Поставь то, что написано в строке; если стоит в необычном месте — задай переменную `MCW_*` |
| При старте игры «There were errors compiling scripts» | Ответь «Нет», запусти `mcw doctor`. Возможен конфликт с другим скриптовым модом — попробуй без него |
| Нет руки и HUD Minecraft поверх Ведьмака | Нет `overlay\mcw_overlay.exe` (см. «Что нужно») или клиент ещё стартует (15–40 с) |
| Блоки — ящики | Лайт-режим: REDkit не стоит или `-Lite` |
| В игре ничего не происходит | `mcw status`; журнал моста `bridge\logs\bridge.log` (UTF-8: `Get-Content bridge\logs\bridge.log -Tail 30 -Encoding UTF8`) |
| Упал шаг установки | Его журнал — в `%LOCALAPPDATA%\mcw\logs` |

Другие журналы: `mc\run\logs\latest.log` (сервер), `mcclient\run\logs\latest.log` (клиент),
`Документы\The Witcher 3\scriptslog.txt` (скрипты Ведьмака).

## Известные проблемы

- Альфа, проверено на одной машине. Установки GOG находятся, но не проверены.
- Настоящие текстуры только у 10 блоков (трава, земля, камень, булыжник, дубовое бревно, доски, песок, верстак,
  листва дуба, стекло); остальные — серые кубы.
- Бой проверен в игре только на гусях и курах. Ещё не проверены в игре: бой с волками и бандитами (баланс урона),
  парирование и уклонение NPC, щит Minecraft, стрелы в стенах, последние правки езды на лошади, тело Стива в
  настоящей катсцене.
- Многие дома Белого Сада сплошные в самом Ведьмаке; сквозь тонкие створки дверей можно пройти.
- Без фокуса Ведьмак встаёт на паузу (так устроен движок, скриптом не обойти).
- Сейвы, сделанные с модом, игра помечает как модифицированные (как с любым скриптовым модом).

## Как устроено

```
Сервер Minecraft 1.21.11 (Fabric, без окна) ── JSON-строки, 127.0.0.1:25600 ──┐
Скрытый клиент Minecraft (Fabric-мод mcwc) ─── JSON-строки, 127.0.0.1:25601 ──┤
                                                                              мост (Python) ── debug exec, 127.0.0.1:37001 ── Ведьмак 3 (скрипты modMCW)
Оверлей (Windows.Graphics.Capture, цветовой ключ) ── рисует руку и HUD клиента поверх окна Ведьмака
```

| Папка | Что |
|---|---|
| `mcw.ps1`, `mcw.cmd` | Установщик и запуск |
| `spike/` | Скриптовый мод Ведьмака (`mod/modMCW`), клиент отладочного канала и инструменты |
| `mc/` | Fabric-мод сервера (Java 21) |
| `mcclient/` | Fabric-мод скрытого клиента (Java 21) |
| `bridge/` | Мост (Python, только стандартная библиотека) |
| `overlay/` | GPU-оверлей (C++) |
| `tools/` | Инструменты для файлов Ведьмака и сборка блоков и моделей через REDkit |
| `docs/` | Документация разработчика: [DEVELOPMENT](docs/DEVELOPMENT.md) (запуск руками, устройство, план), [NOTES](docs/NOTES.md) (проверенные факты о движке), [PLAN](docs/PLAN.md), [REDKIT](docs/REDKIT.md), [STEVE](docs/STEVE.md) |

Тесты: `python -m pytest -q` в `spike/`, `bridge/`, `tools/` и `mc/` (`test_fake_bridge.py`); `ruff check .`;
`python spike/ws_lint.py spike/mod/modMCW/content/scripts/local/*.ws` (нужна игра — индекс ванильных скриптов).
Зависимости для разработки: `pip install -r requirements-dev.txt`.
